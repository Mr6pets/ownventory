# 路线图

物序项目的开发将按照以下阶段进行，每个阶段都有明确的目标和交付物。

## Phase 0: 项目初始化与方案 (已完成)

### 目标
建立项目基础架构，完成技术选型和文档。

### 已完成工作
- [x] 项目需求分析和关键假设
- [x] 技术栈选择和理由
- [x] monorepo目录结构设计
- [x] 数据模型设计
- [x] MVP任务分解和风险清单
- [x] 项目基础结构初始化
- [x] README和架构文档
- [x] 技术决策记录(ADR)

### 下一步
等待Phase 0 review，然后进入Phase 1。

## Phase 1: 本地优先 MVP

### 目标
实现核心功能，支持本地使用，无需登录。

### 计划任务
1. **packages/core**: 领域模型与Zod schema
2. **packages/db**: SQLite数据层实现
3. **apps/web**: 基础Web应用框架
4. **物品CRUD**: 基本的物品增删改查
5. **分类与标签**: 基础的分类和标签管理
6. **位置管理**: 树形位置结构
7. **附件管理**: 图片和文件上传
8. **搜索筛选**: 基础搜索功能
9. **CSV/JSON导入导出**: 数据导入导出
10. **基础测试**: 单元测试和E2E冒烟测试

### 交付物
- 可运行的Web应用，支持本地物品管理
- 基础的CRUD功能
- 分类、标签、位置管理
- 附件上传和查看
- 搜索和筛选功能
- 数据导入导出

## Phase 2: 提醒、借用、统计

### 目标
添加高级功能，提升用户体验。

### 计划任务
1. **提醒系统**: 保修/维护/借用提醒
2. **借用管理**: 借用记录和归还流程
3. **维护任务**: 维护计划和记录
4. **统计仪表盘**: 基础数据统计
5. **响应式UI**: 完善移动端适配
6. **中文界面**: 本地化支持

### 交付物
- 完整的提醒系统
- 借用管理功能
- 维护任务管理
- 统计仪表盘
- 响应式界面
- 中文界面

## Phase 3: 账号与可选同步

### 目标
添加账号系统，支持云同步。

### 计划任务
1. **认证系统**: 邮箱魔法链接
2. **云端数据库**: PostgreSQL集成
3. **附件对象存储**: S3兼容存储
4. **同步逻辑**: 本地与云端同步
5. **冲突解决**: 基础冲突处理策略
6. **移动端接入**: React Native集成
7. **桌面端接入**: Tauri集成

### 交付物
- 认证系统
- 云同步功能
- 附件云存储
- 移动端应用
- 桌面端应用
- 同步冲突解决

## Phase 4: 移动端与桌面端完善

### 目标
完善移动端和桌面端体验。

### 计划任务
1. **Expo移动端**: 拍照和扫码功能
2. **Tauri桌面端**: 本地文件操作
3. **批量导入导出**: 支持批量操作
4. **离线优化**: 离线使用体验提升
5. **性能优化**: 列表虚拟化，图片优化

### 交付物
- 完善的移动端功能
- 完善的桌面端功能
- 批量操作支持
- 离线体验优化
- 性能提升

## Phase 5: 扩展能力

### 目标
添加高级功能，满足更复杂需求。

### 计划任务
1. **条码扫描**: 物品快速录入
2. **AI功能**: 自然语言录入，图片识别
3. **家庭共享**: 多人共享和权限管理
4. **保险报告**: 保险理赔清单
5. **维护历史**: 维修记录和耗材周期
6. **购物清单**: 购物清单与"是否已拥有"查询
7. **高级同步**: 冲突解决优化，审计日志
8. **多币种支持**: 汇率、折旧、资产统计

### 交付物
- 条码扫描功能
- AI录入功能
- 家庭共享功能
- 保险报告功能
- 维护历史功能
- 购物清单功能
- 高级同步功能
- 多币种支持

- 代码质量达标
- 用户可测试和审查
