# 架构设计

## 概述

物序采用模块化单体架构，基于monorepo实现跨端复用。核心设计原则包括：

- **本地优先**：未登录也能完整使用
- **隐私优先**：默认本地存储，云同步可选
- **跨端复用**：共享包支持多端使用
- **渐进式扩展**：模块化设计支持功能逐步添加

```
│  packages/ui    │  packages/core    │  packages/db   │

          │                │                │

```

## 核心组件设计

### 1. 共享包层 (packages/)

#### packages/core
- **职责**: 领域模型、业务逻辑、Zod schema
- **特点**: 纯TypeScript，无UI依赖，可离线使用
- **内容**:
  - 领域实体定义 (User, Item, Category等)
  - 业务逻辑 (CRUD操作、验证逻辑)
  - Zod schema验证
  - 类型定义和接口

#### packages/ui
- **职责**: 跨端UI组件库
- **特点**: 基于shadcn/ui，支持Web、移动、桌面
- **内容**:
  - 基础组件 (Button, Input, Table等)
  - 业务组件 (ItemCard, CategoryTree等)
  - 设计系统 (主题、颜色、间距)

#### packages/db
- **职责**: 数据库抽象和ORM封装
- **特点**: 支持SQLite和PostgreSQL
- **内容**:
  - Drizzle schema定义
  - 数据库迁移
  - 查询和事务封装
  - 本地存储管理

#### packages/sync
- **职责**: 离线同步逻辑
- **特点**: 支持冲突解决，增量同步
- **内容**:
  - 同步变更记录
  - 冲突检测和解决
  - 同步状态管理

#### packages/config
- **职责**: 配置管理
- **特点**: 环境配置和常量
- **内容**:
  - 环境变量管理
  - 默认配置
  - 常量定义

### 2. 应用层 (apps/)

#### apps/web
- **技术**: Next.js + React + Tailwind CSS
- **特点**: 响应式PWA，支持离线使用
- **职责**:
  - Web界面实现
  - 路由管理
  - PWA功能

#### apps/mobile
- **技术**: React Native + Expo Router
- **特点**: 跨平台移动应用
- **职责**:
  - 移动端界面
  - 设备功能集成（相机、扫码）

#### apps/desktop
- **技术**: Tauri
- **特点**: 轻量桌面应用
- **职责**:
  - 桌面端界面
  - 本地文件操作

#### apps/api
- **技术**: Fastify + tRPC
- **特点**: REST/tRPC混合API
- **职责**:
  - 认证和授权
  - 云同步服务
  - 附件管理
  - 数据同步

## 数据流设计

### 本地使用流程
```
用户操作 → UI组件 → packages/core → packages/db → SQLite
```

### 云同步流程
```
用户操作 → UI组件 → packages/core → packages/sync → apps/api → PostgreSQL
```

## 扩展性设计

### 模块化设计
- 每个包职责单一，便于独立开发和测试
- 包间依赖清晰，避免循环依赖
- 支持渐进式功能添加

### 数据模型扩展
- 预留扩展字段，支持自定义字段
- 软删除支持，便于数据恢复
- 版本控制，支持数据迁移

### 同步机制
- 增量同步，减少网络传输
- 冲突解决策略可配置
- 支持断点续传

## 安全设计

### 数据安全
- 本地存储加密
- 云同步数据传输加密
- 敏感信息脱敏

### 访问控制

- 细粒度的数据访问控制
- 操作审计日志
