# ADR 0001: 技术栈选择

## 基本信息

- **日期**: 2026-10-24
- **状态**: 已批准
- **负责人**: 架构团队

## 决策概述

选择物序应用的技术栈，基于"跨端复用、本地优先、隐私优先"的核心原则。

## 技术栈选择

### Monorepo
- **选择**: pnpm + Turborepo
- **理由**:
  - 优秀的包管理，缓存优化
  - TypeScript原生支持
  - 良好的工作区管理
  - 社区活跃，文档完善

### Web应用
- **选择**: Next.js + React + Tailwind CSS + shadcn/ui
- **理由**:
  - 全栈能力，服务器端渲染
  - 组件库成熟，生态丰富
  - PWA支持，可离线使用
  - TypeScript支持良好

### 移动端
- **选择**: React Native + Expo Router
- **理由**:
  - 跨平台，代码复用率高
  - TypeScript支持
  - 开发体验好，热重载
  - 社区活跃，插件丰富

### 桌面端
- **选择**: Tauri
- **理由**:
  - 轻量，基于Web技术
  - 性能好，打包体积小
  - 跨平台支持
  - 与Web技术栈一致

### 后端
- **选择**: Node.js + Fastify + tRPC
- **理由**:
  - 轻量，启动快
  - TypeScript原生支持
  - tRPC优于REST，类型安全
  - Fastify性能优秀

### 数据库
- **选择**: SQLite (本地) + PostgreSQL (云端)
- **理由**:
  - SQLite: 轻量，嵌入应用，支持离线
  - PostgreSQL: 功能完整，支持复杂查询
  - 符合本地优先原则

### ORM
- **选择**: Drizzle
- **理由**:
  - TypeScript优先，类型推导好
  - 轻量，启动快
  - 现代API设计
  - 足够的功能满足MVP需求

### 校验
- **选择**: Zod
- **理由**:
  - TypeScript集成好
  - 运行时校验
  - Schema定义清晰
  - 支持复杂验证

### 数据请求
- **选择**: TanStack Query
- **理由**:
  - 状态管理，缓存
  - 离线支持
  - TypeScript支持
  - 生态成熟

### 测试
- **选择**: Vitest + Playwright
- **理由**:
  - 现代测试框架
  - E2E测试支持
  - TypeScript支持
  - 性能优秀

### CI
- **选择**: GitHub Actions
- **理由**:
  - 生态成熟
  - 免费额度充足
  - 与GitHub集成良好

### 本地开发
- **选择**: Docker Compose
- **理由**:
  - 环境一致性
  - 简化依赖管理
  - 支持PostgreSQL + 对象存储

### 附件存储
- **选择**: 本地文件 + 可选S3兼容对象存储
- **理由**:
  - 本地优先，支持离线
  - 云存储可选，扩展性强
  - 兼容多种对象存储服务

### 认证
- **选择**: 邮箱魔法链接
- **理由**:
  - 简单，无密码
  - 隐私友好
  - 实现相对简单

## 替代方案考虑

### ORM替代方案
- **Prisma**: 功能更完整，但更重，启动较慢
- **Drizzle**: 轻量，TypeScript优先，符合当前需求

### 认证替代方案
- **OIDC**: 更标准，但实现复杂
- **邮箱魔法链接**: 简单，隐私友好，符合MVP需求

## 风险评估

### 主要风险
1. **Drizzle社区较小**: 可能遇到文档不足的问题
   - 缓解: 选择成熟稳定的版本，必要时贡献文档

2. **邮箱魔法链接实现复杂**: 可能影响用户体验
   - 缓解: 使用成熟库，充分测试

3. **跨端一致性**: 不同端可能有体验差异
   - 缓解: 共享UI组件，统一设计系统

## 决策影响

### 积极影响
- 跨端代码复用率高
- TypeScript全栈，类型安全
- 本地优先，支持离线使用
- 隐私友好，云同步可选

### 消极影响
- 技术栈较新，可能遇到未知问题
- 需要维护多个技术栈
